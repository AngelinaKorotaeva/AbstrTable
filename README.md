# AbstrTable

AbstrTable is a Java project focused on implementing and working with abstract table data structures.

The project was created as a semester assignment and demonstrates object-oriented programming, data management, and custom table operations in Java.

## Features

- Custom abstract table implementation
- Data insertion, deletion, and searching
- Work with structured records
- Object-oriented architecture
- Maven project structure
- JavaFX graphical interface

## Technologies

- Java
- JavaFX
- Maven
